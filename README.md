# Horizon UI Dashboard

Frontend-проект административной панели, разработанный по макету Horizon UI.
Цель проекта - практика создания масштабируемого React-приложения, работы с TypeScript, компонентным подходом и реализацией сложных интерфейсов по Figma-макетам.

## Технологии

* React
* TypeScript
* Vite
* React Router
* SCSS Modules
* Redux Toolkit *(планируется при необходимости)*
* Vite SVG React Plugin

## Реализованный функционал

* Боковая навигация с активными состояниями
* Маршрутизация страниц через React Router
* Работа с SVG-иконками как React-компонентами
* Стилизация компонентов через SCSS Modules

## Планируемый функционал

* Dashboard с аналитическими блоками и графиками
* Таблицы с данными
* Kanban-доска
* Профиль пользователя
* Темная тема
* Работа с API и асинхронными состояниями
* Авторизация пользователя

## Цель проекта

Проект создается как учебно-практическое приложение для углубления навыков frontend-разработки: TypeScript, React-архитектуры, работы с UI-компонентами и интеграции с внешними данными.
